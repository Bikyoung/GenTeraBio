<GenTeraBio>

1. 프로젝트 개요
   - 본 프로젝트는 CAR-T, CAR-NK, MSC 등 세포치료 기술이 빠르게 대두되고 있는 현 시점을 배경으로,
     기존 세포치료 기업들이 공통적으로 가지고 있는 한계를 보완한 이상적인 세포치료 기업을 가상으로 설계하고,
     해당 기업의 공식 홍보 사이트를 제작한 팀 프로젝트입니다.

2. 기획 배경
   - 현실의 세포치료 시장에서는 다음과 같은 한계가 반복적으로 나타납니다.
     - 병원 단독으로는 GMP 제조 인프라 확보가 어려움
     - 연구는 preclinical 단계에 머무르고, 임상 적용은 외부 협력이 필수
     - 기술력은 있으나 임상·공정·QC·데이터 역량이 분산
     - 병원 입장에서 “실제로 함께 임상으로 갈 수 있는 기업”을 판단하기 어려움
  - 본 프로젝트는 이러한 문제를 전제로,
    병원·연구기관이 신뢰할 수 있는 조건을 모두 갖춘 세포치료 기업을 가상으로 설정했습니다.

3. 가상 기업 컨셉
   - 이 사이트에 등장하는 세포치료 기업은 다음 조건을 충족합니다.
     - CAR-T / CAR-NK / MSC 파이프라인 보유
     - GMP 제조 및 세포 가공 역량 확보
     - 공정 개발·QC·임상 지원 경험을 전면에 공개
     - 병원과의 공동연구·기술이전·임상 협력에 적극적인 구조

  - 즉, 투자자·병원·연구자 모두에게 명확한 신뢰 신호를 주는 기업을 목표로 설계되었습니다.

4. 사이트 주요 구성
   - 세포치료 기술 현황
   - CAR-T / CAR-NK / MSC
   - 임상 단계, 적용 질환, 주요 이슈 요약
   - 기업 역량 강조
   - GMP 보유 여부
   - 세포 생산, 공정 개발, QC 역량
   - 임상 및 연구 협력 가능 영역
   - 신뢰 근거 제시
   - 논문, 학회 발표
   - 임상시험 등록 정보(공개 데이터 기반)

5. 프로젝트 목적
   - 세포치료 기업 홍보 사이트의 이상적인 구조 제안
   - 병원–기업 협력 관점에서 설득력 있는 정보 배치 연습
   - 바이오·헬스케어 분야 웹 서비스 기획 및 구현 역량 포트폴리오화

6. Note
   - 본 프로젝트에 등장하는 기업, 데이터, 파이프라인은 모두 가상 설정입니다.
   - 실제 의료·임상 판단을 목적으로 하지 않으며,
     세포치료 기업 홍보 사이트 UI/UX 및 정보 구조 연구를 위한 프로젝트입니다.
